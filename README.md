# CTF AES-CBC Decryptor

Et verktøy for å løse CTF/krypteringsoppgaver med AES-CBC, spesielt egnet for digitale spor-oppgaver som PST bruker i sine jobbsøk-prosesser.

## 🚀 Installering

```bash
# Clone repository
git clone <your-repo-url>
cd digitale_spor_ctf_solver

# Create virtual environment (optional but recommended)
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
